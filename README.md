# DonutVault

A personal watch archive for the anime, movies, and series you watch. DonutVault is built with HTML, CSS, and vanilla JavaScript; your collection is saved in the current browser using LocalStorage.

## Run locally

Open `index.html` in a browser. No backend, database, build step, or package installation is required.

## Features

- Dashboard with collection totals and recently added titles.
- Watch library with search, category/status filters, sorting, title details, and editing.
- Watch history for completed titles and recorded watch dates.
- Add and edit forms with validation.
- JSON collection import and export.

Your LocalStorage collection belongs to this browser and device. It does not automatically sync across devices. Use the library's **Export JSON** action to make a backup.
